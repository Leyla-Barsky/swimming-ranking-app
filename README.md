# 🏊‍♂️ Israel Swimming Ranking Dashboard | מאגר דירוג שחייה - ישראל

A high-performance React web application designed to track, filter, and rank competitive swimming results across Israel. The platform aggregates data from official racing platforms and provides an intuitive, sport-standard filtered interface for swimmers, coaches, and families.

## ✨ Key Features
* **Advanced Filtering & Search:** Filter by swimming style/discipline, gender, pool length (50m/25m), birth year ranges, and specific date periods.
* **Smart Sport Sorting:** Automatically sorts results by official swimming discipline order (Free, Back, Breast, Fly, IM) and ranks times accurately from fastest to slowest.
* **AQUA Points Integration:** Displays official AQUA performance points alongside race times.
* **Responsive Modern UI:** Built with clean CSS and React state management, optimized for both desktop and mobile views.
* **Automated Data Pipeline:** Custom Node.js & Playwright scraping scripts to ingest, clean, and structure race results into a master JSON database.

## 🛠️ Tech Stack
* **Frontend:** React (Vite), JavaScript (ES6+), HTML5, CSS3
* **Data Scraping & Processing:** Node.js, Playwright
* **Version Control:** Git & GitHub
